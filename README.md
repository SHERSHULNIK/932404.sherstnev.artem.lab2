# Лабораторная работа №2

## Тема

Подключение CSS, работа с селекторами, типографикой, цветами, отступами,
позиционированием и псевдоклассами.

## Выполненные требования

- Перенесен файл html с предыдущей лабораторной работы и соответственно создан новый репрезеторий.
- Основные стили страницы вынесены во внешний файл [style.css](style.css).
- В `:root` объявлены CSS-переменные для цветов, теней и шрифта.
- Для элементов продемонстрированы разные виды позиционирования:
	`static` для подвала, `relative` для секций и карточек проектов,
	`absolute` для значка «Избранное».
- Добавлены состояния элементов `:hover`, `:active`, `:focus` и `:visited`.
- Секции «Навыки», «Проекты» и «Обратная связь» подсвечиваются при наведении
	курсора мыши.
- Для кнопки отправки формы при фокусе отображается белая рамка толщиной 3px.
- В секцию проектов добавлены изображения с информативными `alt` и обёрткой
	`<figure>`.
- Внутри HTML размещён блок `<style>` со стилями для `textarea`: увеличенная
	высота, внутренняя тень и моноширинный шрифт.
- Для `aside` задан inline-стиль с полупрозрачным белым фоном.
- Основной цвет интерфейса — фиолетовый, акцентный цвет — белый.
- Контраст цветов текста и фона подобран с учётом требования не менее 4.5:1.

## Октаз от условия 

Пришлось отказаться от условия, при котором подсвеичалась область рамки, назодящейся в видимой части страницы, так как страницы обладает небольшим размером. Поэтому я сделал свечение блоков при наведении курсора, что выглядит более уместным.

## Структура страницы

Страница содержит шапку с фотографией и кратким описанием, секции навыков,
проектов и обратной связи.
